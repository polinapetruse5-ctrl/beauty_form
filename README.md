# ÉLÉGANCE WORKWEAR — demonstrācijas interneta veikals

Premium darba apģērba veikala priekšpuses prototips latviešu valodā.

## Palaišana
1. Atarhivējiet ZIP failu.
2. Atveriet `index.html` pārlūkā vai palaidiet lokālu statisko serveri.
3. Produktu dati, cenas, attēli un kategorijas atrodas `app.js` failā.

## Kas ir iekļauts
- Adaptīva sākumlapa un produktu katalogs.
- Kategoriju filtrēšana, kārtošana un meklēšana.
- Grozs ar daudzuma uzskaiti un `localStorage` saglabāšanu.
- Mobilā navigācija.
- Jaunumu vēstules demonstrācijas forma.

## Pirms publicēšanas
Šī ir priekšpuses demonstrācijas versija, nevis pilnībā pieslēgts e-komercijas risinājums. Lai pieņemtu reālus pasūtījumus, nepieciešams:
- Pievienot īstu produktu datubāzi un administrēšanas vidi.
- Pieslēgt maksājumu pakalpojumu sniedzēju.
- Ieviest pasūtījumu apstrādi, piegādes metodes un e-pasta paziņojumus.
- Aizstāt demonstrācijas attēlus ar zīmola produktu fotogrāfijām.
- Pārbaudīt un papildināt privātuma politiku, distances līgumu un atgriešanas noteikumus atbilstoši uzņēmuma faktiskajai darbībai.
- Nomainīt pagaidu zīmola nosaukumu un kontaktinformāciju.

## Faili
- `index.html` — lapas struktūra.
- `styles.css` — dizains un responsīvie stili.
- `app.js` — produktu dati un interaktivitāte.
